# Skywalker X8 Flying-Wing System Identification

**What this establishes:** on NTNU's untouched Skywalker X8 validation maneuvers, the structured-residual model's equal-validation-maneuver rolling errors beat kinematic persistence by 56.2% and the structured model by 13.5%, while the structured model retains the better complete-maneuver open-loop rollout (6.19 m / 23.4 degrees versus 10.8 to 16.7 m for the residual across initialization seeds).

## Purpose

NTNU's pinned [Skywalker X8 system-identification campaign](https://doi.org/10.18710/U4TLYV) is the first materially different real fixed-wing configuration in the Glassbox evaluation matrix: a flying wing with no yaw control, no conventional tail, and normalized throttle plus roll and pitch generalized elevon angles in radians instead of a PX4 topic or hard-coded surface index.

## Data

The campaign contains 17 dedicated, approximately ten-second maneuvers at 40 Hz: 13 upstream training maneuvers and four untouched validation maneuvers. The adapter emits the same rigid-body state contract as every other Glassbox integration but a genuine flying-wing control layout.

The source combines a STIM300 IMU, ArduPilot EKF state, and separately generated surface excitation. It also provides a strong north-west wind estimate whose vertical component was validated by the authors against an earlier five-hole probe flight. Glassbox types the three wind components as trusted NWU context, samples them at rollout initialization, and holds them through each prediction. The lower-rate upsampled GPS position is visibly staircase-like, so the adapter reconstructs local position by trapezoidally integrating the internally consistent 40 Hz EKF velocity and records the GPS endpoint discrepancy.

## Reproduce

```bash
uv run glassbox x8 prepare artifacts/x8_reference
```

Fit both maintained model classes on the exact upstream split:

```bash
uv run glassbox fit \
  artifacts/x8_reference/canonical/training/*.npz \
  artifacts/x8_reference/canonical/validation/*.npz \
  --training-horizons 0.1,0.5,2.0 \
  --skip-no-lag-ablation \
  --model artifacts/x8_reference/structured_model.json \
  --report artifacts/x8_reference/structured_report.json

uv run glassbox fit \
  artifacts/x8_reference/canonical/training/*.npz \
  artifacts/x8_reference/canonical/validation/*.npz \
  --training-horizons 0.1,0.5,2.0 \
  --model-class structured_residual \
  --skip-no-lag-ablation \
  --model artifacts/x8_reference/residual_model.json \
  --report artifacts/x8_reference/residual_report.json
```

Every recording carries an upstream `benchmark_split` label of `training` or
`validation`, so `glassbox fit` reserves the four labeled `validation`
maneuvers regardless of the order the two globs above expand in (passing
`--holdout-count` or `--holdout-profile` here is rejected as unnecessary).

Then run the boundary-safe rolling comparison against constant-velocity, constant-body-rate persistence:

```bash
uv run glassbox x8 evaluate artifacts/x8_reference \
  --structured-model artifacts/x8_reference/structured_model.json \
  --residual-model artifacts/x8_reference/residual_model.json \
  --report artifacts/x8_reference/benchmark_report.json
```

The report's two model entries are named `structured` and `structured_residual`; downstream tools such as the [cross-airframe fixed-wing gate](fixedwing-gate.md) reference these exact names.

## Results

Recorded on 2026-09-01 with rollout error statistics that exclude the shared
initial sample (`metric_policy` v2), the `deterministic_weighted_minibatch_v3`
objective, and per-step logged wind in complete-maneuver rollouts.

The residual's equal-validation-maneuver rolling errors are:

| Horizon | Position [m] | Velocity [m/s] | Attitude [deg] | Angular velocity [rad/s] |
| ---: | ---: | ---: | ---: | ---: |
| 0.1 s | 0.00623 | 0.136 | 0.856 | 0.148 |
| 0.5 s | 0.0607 | 0.277 | 3.72 | 0.188 |
| 1.0 s | 0.151 | 0.375 | 5.62 | 0.191 |
| 2.0 s | 0.486 | 0.679 | 8.72 | 0.192 |

Across every horizon and state metric, its geometric score is 0.438 relative to kinematic persistence and 0.865 relative to the structured model, so it is 56.2% and 13.5% better respectively. The structured model retains the better complete-maneuver rollout: 6.19 m / 23.4 degrees over the four 9-12 second validation maneuvers versus 16.7 m / 45.6 degrees for the residual. The residual's complete-maneuver number is fragile: refitting with four residual initialization seeds gave 10.8, 14.8, 16.5, and 16.7 m (37 to 51 degrees) while its 2 s windowed position error stayed between 0.37 and 0.49 m, so treat the windowed table as the residual's claim and the complete-maneuver figure as one draw. Per-step logged wind in the complete rollout accounts for under 0.4 m of it.

## Boundary

An earlier no-wind ablation observed two-second structured accuracy degrade from 0.548 m / 7.02 degrees to 0.896 m / 24.3 degrees, with every complete maneuver becoming non-finite; this is an unreproduced development observation whose artifact was not retained, and the current evaluator rejects non-trusted-wind specs so it cannot be regenerated with the documented commands.

This is characterization evidence for one flying-wing airframe using a trusted, author-validated wind estimate; it does not claim that every estimator-derived wind source is trustworthy. See the [cross-airframe fixed-wing development gate](fixedwing-gate.md) for how this result is combined with IDF-DS.
